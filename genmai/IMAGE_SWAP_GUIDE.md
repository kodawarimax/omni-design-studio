# 🖼️ 画像の手動入れ替えガイド（2通りの簡単差し替え方法）

本パッケージ（V3）では、`玄米クレンズまとめ` フォルダ内の**実物写真・オリジナル素材のフォルムを最優先で使用**し、すべての画像を `assets/` フォルダに独立分離しています。
後から手動で画像を入れ替える際は、以下の **方法A（フォルダ上書き）** または **方法B（ブラウザ上でドラッグ＆ドロップ／クリック）** のどちらでも一瞬で差し替え可能です。

## 方法B：ブラウザ画面上で直接ドラッグ＆ドロップ／クリックして入れ替える

1. `website.html`、`flyer_a4_double.html`、`packaging_mockup.html`、`uword_banner.html` のいずれかを Chrome 等のブラウザで開きます。
2. **ドラッグ＆ドロップ**: Finder から好きな画像ファイルを、画面上の差し替えたい写真の上に直接ドラッグ＆ドロップすると、その場で即座に写真が入れ替わります。
3. **クリック選択**: 画面左下のツールバーにある **`[クリック/D&Dで画像差替: OFF]`** ボタンをクリックして **ON** にすると、すべての写真が点線枠でハイライトされます。入れ替えたい写真をクリックするとファイル選択画面が開きます。
4. 差し替えが終わったら、ツールバーの **`[💾 差替後のHTMLを保存]`** ボタンを押すと、差し替え済みのHTMLファイルがそのままダウンロードされます。
   - ※印刷時（PDF保存時）には、左下のツールバーや切替ボタンは自動的に非表示になります。
